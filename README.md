# 好韻器 Lucky Hawaii

**v0.96 beta** — 中文歌詞押韻工具

## 功能簡介

輸入注音、拼音或漢字，自動找出同韻腳的字，再搭配 AI 從詞庫中推薦適合歌詞情境的詞語。

- 押韻搜尋：支援韻母（押字尾）、聲母（押字首）、同韻部家族
- AI 建議：從詞庫候選中依情境挑選，而非憑空生成
- 歌詞段落管理：多段落編輯、情境標籤、保留池
- 多模型自動 fallback（Gemini / GitHub Models / Groq）

## 資料來源

- **字庫：** 小麥注音（data-plain-bpmf）
- **詞庫：** 唯音輸入法（vChewing VanguardLexicon）+ 新酷音詞庫（libchewing tsi.csv，LGPL-2.1-or-later）
